3. Reynolds-similarity test inside a single facility (Liu2024, balanced 5x4 factorial in Omega and chamber pressure)
==============================================================================
If Cp = f(Re) with Re ~ rho*Omega, then in
    log Cp = c + alpha*log(Omega) + beta*log(rho)
Reynolds similarity requires alpha = beta.  H0: alpha - beta = 0.
Because R and T are fixed, M_tip ~ Omega, so alpha - beta is exactly
the exponent of the second group (Mach -- or, indistinguishably, g-level).
